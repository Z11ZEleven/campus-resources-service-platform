# 第一次讨论课准备清单

课堂要求：需求基线；任务分解与依赖关系；架构搭建和第一次迭代功能；项目级规则文件与 AI 协作方式；风险识别。重点是推进项目并提出真实问题。

## 准备材料

- [ ] 需求草案经团队评审成为基线，逐项有验收标准和待定事项。
- [ ] 分工、公共层归属及决策依据已填写。
- [ ] Issues 展示负责人、任务依赖和当前进度。
- [ ] 技术方案与模块边界经评审，实际工程能启动。
- [ ] 完成并现场演示第一轮功能，建议为登录、查询、预约、查看记录。
- [ ] AGENTS.md 和协作规则经人工评审。
- [ ] 展示一次 AI 方案、实现、人工发现问题、验证与 PR 的真实过程。
- [ ] 展示实际构建测试或部署进展，不将规划描述成已完成。
- [ ] 准备风险、候选应对方案与希望课堂讨论的问题。

## 第一轮任务依赖

技术决策 → 工程和配置 → 数据迁移/种子资源 → 真实教室查询 → 前后端联调。

身份权限和预约契约可并行设计；实现预约依赖用户、主数据与并发控制。M2/M3 同期细化需求、状态机和接口，不等待 M1 全部完成。

## 待创建/认领的 Issues

1. 评审需求与公共层归属。
2. 确认技术框架、版本、接口规范及部署拓扑。
3. 初始化前端和后端，提供健康检查。
4. 建立迁移和幂等种子数据，提供真实教室查询。
5. 接通页面与接口。
6. 建立 CI 的实际构建、类型检查与行为测试。
7. 实现基础登录权限与首条预约链路。
8. 建立测试环境自动部署及操作说明。

每项 Issue 必须补充负责人和具体验收标准。此清单不是已经创建的 GitHub Issues。
