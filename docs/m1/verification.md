## 3. 验证行为

- 会话：有效 Cookie 恢复、退出撤销、过期拒绝、失效身份/角色实时生效、外部 Origin 和缺失 CSRF 拒绝；登录 JSON 不返回 HttpOnly 会话凭据。
- 授权：院系隔离、资源范围查询/计数/维护、不同角色动作和范围不能拼接、M1 本人记录及学生身份适配；SYS_ADMIN 不隐式获得业务权限。
- 服务主体：凭据摘要、模块绑定、房间范围、轮换/停用、审计及幂等配置；初始化管理员与重复种子不会恢复被撤销授权或停用账户。
- 主数据：建筑关系、唯一性、座位不可跨室、软停用、版本/审计；已有有效来源与破坏性维护冲突时明确409。
- 开放：连续完整覆盖、分段空隙、相邻合并、跨午夜、午夜终点、特殊开启/关闭、关闭优先、小时内关闭影响整个可预约槽。
- 模型：非法区间、状态、座位/身份组合归属、重复创建请求键、违约唯一、签到记录归属及不保存提交编码。
- 来源/占用：重复获取不生成重复明细、M2 展开有效座位、释放只更新对应来源明细、维修来源不受个人取消影响，多个维修工单释放仍隔离。
- 迁移：空库到0007、重复升级、模型一致性、从0003携合成来源/释放记录/通知升级、完整测试回放、旧M3资料保留；不虚构旧M1预约。多身份/局部角色不能有损降级为旧结构。
- HTTP：进程健康与真实数据库ready分离、真实拒绝连接时503；业务错误、校验错误、404/405和未知异常均有服务器请求ID与脱敏结构，故障后数据库事务回滚。
- Outbox 登记：同键同载荷幂等、异载荷或业务版本冲突409、业务事务回滚同时撤销任务；事件只在调用方提交后可见。
- 租约与并发：同刻第二个 Worker 领取不到已锁任务；租约过期后可被新 Worker 领取并获得新令牌；旧令牌或旧版本完成操作被拒绝；两个 Worker 并发领取各拿不同事件。
- 崩溃恢复：模拟领取进程未完成且租约到期，另一 Worker 重新领取并成功投递，尝试次数增加且只产生一条通知。
- 重试与故障：瞬时失败写回 `PENDING`/`TRANSIENT` 并按退避延迟；达到上限写 `MANUAL`/`RETRY_EXHAUSTED`；未知处理器和非法载荷写 `MANUAL`/`PERMANENT`；故障查询可列出。
- 接收幂等：通知接收方已提交但 Worker 未完成时，重投仍只有一条站内通知；审计接收方同样只有一条记录，事件最终 `SUCCEEDED`。
- 审计操作者：`SYSTEM` 不填用户 ID，`SERVICE` 使用服务主体 ID，`USER` 必须提供用户 ID；服务主体 ID 未被当作学生用户。
- M1 适配：预约、通知任务、审计任务同一事务登记；提交后 Worker 投递真实站内通知和审计；回滚后预约、通知任务和审计任务均不存在。
